Study RPG v1.3.4

- Android APK notification permission added.
- Friend request notification record added.
- Friend message notification record added.
- In-app/mobile local notification bridge added for new friend requests and messages.
- Update popup now shows release notes when a new GitHub Release is available.
- Message box UI improved with Messenger-style alignment.
- Message status added: single tick = sent, double tick = delivered, colored double tick = seen.
- Friends page now has a compact Block list button.
- Blocked users can be unblocked from the Block list.
- Firebase rules updated for notifications, push tokens, friends, and messages.

Note: Device/local notification works from app-side events and saved notification records. For guaranteed notification delivery when the app is fully closed/killed, Firebase Cloud Messaging server/Cloud Functions deployment is required with the saved push tokens.
